# NeetCode 150 — Python Solutions

A collection of Python solutions for the [NeetCode 150](https://neetcode.io/roadmap) coding interview roadmap.

## Contents

The solutions are organized by problem category, including:

- Arrays & Hashing
- Two Pointers
- Sliding Window
- Stack
- Binary Search
- Linked List
- Trees
- Tries
- Heap / Priority Queue
- Backtracking
- Graphs
- Advanced Graphs
- 1-D Dynamic Programming
- 2-D Dynamic Programming
- Greedy
- Intervals
- Math & Geometry
- Bit Manipulation

## Running the Solutions

Make sure Python 3.9 or later is installed, then run any solution from the repository root:

```bash
python path/to/solution.py
```

Some files may include example test cases or functions intended to be imported into a test runner.

## Disclaimer

These solutions are intended for learning and interview preparation. Try solving each problem yourself before reviewing the implementation.
